# notes.json 结构（讲义源文件）

`unfold_build` 吃这个 JSON。字段名照抄，不要自创。

```json
{
  "title": "讲义标题（不是论文标题；是这堂课的标题）",
  "subtitle": "一句话说明这份讲义解决什么问题",
  "goal": "用户这次想学到什么（用他自己的话）",
  "start": "用户的起点（用他自己的话）",
  "path": [
    { "title": "第 1 站", "why": "为什么必须经过它" },
    { "title": "第 2 站", "why": "…" }
  ],
  "sections": [
    {
      "id": "s1",
      "level": 1,
      "title": "结论式标题，不是话题名",
      "summary": "一句话概括这一节（折叠时会露出来）",
      "blocks": [
        {
          "id": "b1",
          "kind": "p",
          "md": "正文。支持 **粗体**、*斜体*、`代码`、$行内公式$、[文字](https://…)。",
          "note": "可选：旁注，小字显示",
          "cites": [{ "doc": "p1", "page": 4, "quote": "原文里连续的一句或几句（会被定位并截图）" }]
        }
      ]
    }
  ],
  "lecture": [
    { "block": "b1", "say": "口语讲稿，1–2 句", "anim": "写代码", "point": true }
  ],
  "quiz": [{ "q": "讲完自己答一遍的问题", "a": "答案" }]
}
```

## 字段

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| `title` | ✅ | 讲义标题。可以是「Transformer 为什么能并行」这种结论句。 |
| `subtitle` | | 副标题：这份讲义的范围。 |
| `goal` / `start` | | 摸底得到的原话，会以「目标 / 起点」两个标签显示在封面。 |
| `path` | | 最短路线，3–6 站，`why` 说明为什么必须经过。 |
| `sections[]` | ✅ | 至少一节。 |
| `sections[].id` | | 省略则自动 `s1`、`s2`…；给 `lecture` 引用时要用到。 |
| `sections[].level` | | 1 = 章（讲义骨架），2 = 节，3–4 = 更细的层。折叠按这个分级。 |
| `sections[].title` | ✅ | **写结论**，不写话题。 |
| `sections[].summary` | | 一句话，折叠成提纲时显示。 |
| `blocks[]` | ✅ | 每节至少一段。 |
| `blocks[].id` | | 省略则自动 `b1`、`b2`…；`lecture` 靠它定位。 |
| `blocks[].kind` | | 见下表，默认 `p`。 |
| `blocks[].md` | ✅ | 正文。多行会被拆成多段（`list` 时每行一项）。 |
| `blocks[].note` | | 旁注，小字、带竖线，适合「注意这里的符号和上一节不同」。 |
| `blocks[].cites[]` | | 这一段的证据。见下。 |
| `lecture[]` | | 讲课节拍，按顺序讲。8–20 个。 |
| `lecture[].block` | ✅ | 必须是已存在的 block id。 |
| `lecture[].say` | ✅ | 口语，1–2 句，≤60 字。 |
| `lecture[].anim` | | 大肥鱼姿态：`写代码` / `轻快记录` / `深度思考碎碎念` / `原地敲击桌面互动`。 |
| `lecture[].point` | | 写 `true` 时讲到这里激光笔指过来（默认不指）。重要结论才写。 |
| `quiz[]` | | 结尾的自测题，折叠答案。 |

## block 的 kind 与显示效果

| kind | 用途 | 外观 |
| --- | --- | --- |
| `p` | 普通段落，讲义主体 | 正文 |
| `key` | 这一节必须记住的结论 | 蓝边框卡片 +「记住这一点」 |
| `def` | 术语定义 / 缺的前置知识 | 灰紫卡片 +「定义」 |
| `ask` | 停下来想一想的问题 | 琥珀色卡片 +「停下来想一想」 |
| `note` | 补充说明（可以整段当旁注） | 小字 + 竖线 |
| `list` | 要点列表（`md` 每行一项，`-` 可省略） | 项目符号 |
| `code` / `formula` | 代码块 / 独立公式 | 深色代码块 / 居中公式 |
| `quote` | 短引用（有 `cites` 时配合使用） | 斜体引用块 |

## cites 与正文编号

正文里的 `[1]`、`[2]` 对应本段 `cites` 数组的下标（`[1]` → `cites[0]`）。
鼠标悬停或点击角标，会弹出**原 PDF 那一页的截图**和引文原文。

- `doc`：`unfold_ingest` 返回的文档 id（`p1`、`p2`…）。
- `page`：页码，从 1 开始。
- `quote`：**原文原句**，直接复制。不要改写、不要翻译、不要省略号。
  定位规则是「这一页上连续几行的文字」，所以跨行没关系，跨页不行。
- `label`：可选，用于说明（目前只做记录）。

定位失败的常见原因：句子被改动过、夹了省略号、跨页、或者页码错了。
先用 `unfold_search` 搜关键短语确认页码和原句，再粘进来。
